# style-guide: 한국어 스타일 일관성 검사기

## 목적

문법적으로 맞는 문장이라도 같은 사이트 안에서 어조와 용어가 들쭉날쭉하면 품질이 떨어진다. SolPlanit 전체에서 같은 개념을 같은 말로 표현하고, 일반 사용자가 이해하기 쉬운 문체를 유지한다.

## 검사 우선순위

1. 어조와 격식
2. 용어 통일
3. 숫자와 단위
4. 목록 구조
5. 인용과 강조
6. 날짜와 시간
7. 링크와 참조

## SolPlanit 기본 스타일

- 사용자 화면은 자연스러운 `~해요/~합니다` 계열을 문맥에 맞게 사용하되 한 화면 안에서 섞지 않는다.
- 사용자를 `유저`, `이용자`로 오가며 부르지 않는다. 기본 표현은 `사용자`다.
- 기술 용어가 꼭 필요하지 않으면 쉬운 한국어를 먼저 쓴다.
- `설치 가능 용량`, `예상 발전량`, `예상 절감액`, `내가 부담할 금액`처럼 결과가 바로 이해되는 표현을 우선한다.
- 같은 개념에 `정밀 분석`, `상세 분석`, `프로 분석`을 섞지 않는다. 사용자 화면에서는 가능한 한 행동이나 결과 중심으로 이름을 짓는다.
- 날짜는 데이터·출처 문맥에서는 `YYYY-MM-DD` 또는 사이트에서 정한 한 가지 형식을 유지한다.
- 숫자와 단위 표기는 같은 화면에서 통일한다. `3 kW`와 `3kW`를 섞지 않는다.
- 버튼은 명사보다 행동을 우선한다. 예: `계산`, `분석`보다 `계산하기`, `자세히 계산하기`.
- 링크 문구는 `여기`, `클릭` 대신 목적을 말한다. 예: `계산 기준 보기`.

## 사용자 화면에서 피할 표현

- 불필요한 한자어와 명사 나열
- 회사 소개서 같은 추상어
- 같은 뜻을 반복하는 설명
- 영어 원문을 직역한 문장 구조
- 사용자가 알아야 할 이유가 없는 업계 용어

## 검수 순서

1. 화면 목적과 대상 사용자를 확인한다.
2. 같은 개념이 다른 이름으로 쓰였는지 찾는다.
3. 버튼, 라벨, 도움말, 오류 메시지의 어조를 맞춘다.
4. 숫자·단위·날짜 형식을 통일한다.
5. grammar-checker로 문법을 확인한다.
6. humanizer로 번역체와 AI스러운 리듬을 마지막으로 다듬는다.
