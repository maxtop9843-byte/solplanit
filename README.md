# SolPlanit

복잡한 태양광 설치, 더 쉽게.

**태양광 설치, 처음부터 끝까지 한 번에.**

SolPlanit은 한국 사용자를 위한 태양광 설치 의사결정 플랫폼입니다. 일반 사용자는 건물 정보와 설치 면적을 입력해 설치 가능 용량, 예상 발전량, 수익·절감액을 확인하고 견적을 요청할 수 있습니다. 전문가는 프로젝트 분석 도구와 커뮤니티를 통해 실제 수요와 연결됩니다.

## 제품 구조

- 일반 사용자: `/home`
- 전문가: `/pro`
- 커뮤니티·견적: `/community`

## MVP

1. 설치 가능 용량 계산
2. 수익·절감액 계산
3. 계산 결과 기반 견적 요청
4. 전문가 프로젝트 분석
5. 설치 사례·질문·전문가 답변 커뮤니티

## 디자인 방향

- 첫 화면은 넓은 여백과 실제 태양광 설치 이미지를 중심으로 구성
- 메인 CTA는 검정색
- 초록색은 선택 상태, 진행 단계, 계산 결과에만 제한적으로 사용
- Apple식 정보 절제, Awesomic식 이미지 활용, Linear식 상태 전환 모션
- 애니메이션은 장식이 아니라 계산 흐름과 다음 행동을 안내하는 용도로만 사용

## 상태

초기 제품 설계 및 개발 기반 구축 중입니다.
