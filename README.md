# SolPlanit

복잡한 태양광 설치, 더 쉽게.

**태양광 설치, 처음부터 끝까지 한 번에.**

SolPlanit은 한국 사용자를 위한 태양광 설치 의사결정 플랫폼입니다. 일반 사용자는 건물 정보와 설치 면적을 입력해 설치 가능 용량, 예상 발전량, 수익·절감액을 확인하고 견적을 요청할 수 있습니다. 전문가는 프로젝트 분석 도구와 커뮤니티를 통해 실제 수요와 연결됩니다.

## 제품 구조

- 일반 사용자: `/home`
- 전문가: `/pro`
- 커뮤니티·견적: `/community`

## MVP

1. 설치 가능 용량 계산
2. 수익·절감액 계산
3. 계산 결과 기반 견적 요청
4. 전문가 프로젝트 분석
5. 설치 사례·질문·전문가 답변 커뮤니티

## 디자인 방향

전체 규정은 [`DESIGN.md`](./DESIGN.md)에 있습니다. 요약하면:

- 배경은 파치먼트(`#fdfdf7`), 순백은 넓은 면적에 쓰지 않습니다
- 포인트 컬러는 스카이 블루(`#0096f7`) 하나뿐이며 행동 요소에만 사용합니다
- 위계는 크기와 여백으로 만들고, 굵은 웨이트로 강조하지 않습니다
- 모든 색·타입·간격·라운딩은 `globals.css`의 토큰을 경유합니다
- 시공 결과물·현장·고객 사진은 실사진만 사용합니다
- 히어로의 하늘→패널 전환은 첫 화면 안에서 완결됩니다
- 애니메이션은 장식이 아니라 상태를 설명하는 용도로만 사용하며,
  `prefers-reduced-motion`을 존중합니다
