# 2026 주택용 태양광 지원 데이터 운영 규칙

`DATA-001`은 설치비 계산기와 보조금 조회가 임의의 전국 평균값을 만들지 않도록 공식 지원 정보를 구조화하는 작업이다.

## 데이터 위치

- `src/lib/support/residentialSolarSupport2026.ts`
- 조회 결과는 `available / confirmed-none / unverified`를 구분한다.
- 데이터셋에 지역이 없다는 이유만으로 `지원 없음`으로 판단하지 않는다.

## 필수 필드

모든 레코드는 다음 정보를 함께 저장한다.

- 연도
- 지역과 적용 범위
- 지원 대상
- 적용 용량
- 지원액 또는 지원율
- 확인일
- 공식 출처 URL

지원율이 `약 30%`, `30% 수준`처럼 공고에서 범위성 표현을 사용하면 `qualifier: "about"`으로 보존한다. 정확한 금액처럼 바꾸지 않는다.

## 현재 확인한 공식 출처

### 서울특별시 관악구

- 출처: 관악구 `태양광보급 지원`
- 2026년 주택지원사업 승인을 받은 관악구 단독주택의 3kW 설비에 관악구 추가 지원 1,000,000원을 안내한다.
- 같은 페이지에 한국에너지공단 지원 1,650,000원이 별도 표시되어 있으므로 관악구 레코드에는 구비 1,000,000원만 저장해 중복 합산을 막는다.

### 경기도

- 출처: 경기도 공고 제2026-789호 `2026년도 경기도 주택태양광 지원사업 공고`
- 경기도 소재 주택 3kW 설비에 도비 40%를 지원하며 총 사업비 상한은 4,541,000원이다.
- 시군비는 지역별로 다르므로 경기도 공통 레코드에 임의의 시군 금액을 넣지 않는다.

### 경기도 의정부시

- 출처: 의정부시 공고 제2026-750호 `2026년 의정부시 주택태양광 지원사업(도지원) 공고`
- 3kW 이하 설비 설치비의 `30% 수준` 시비 지원을 안내한다.
- 해당 표현은 확정 30%가 아니라 공고의 표현을 보존하기 위해 `qualifier: "about"`으로 저장한다.

## 갱신 절차

1. 정부, 한국에너지공단, 광역·기초지자체의 원문 공고 또는 공식 사업 안내만 사용한다.
2. 블로그, 시공사, 뉴스 기사, 검색 요약에서 본 숫자를 원본 확인 없이 넣지 않는다.
3. 새 공고를 확인하면 기존 레코드를 덮어쓰기 전에 연도, 지역, 대상, 용량, 지원액·지원율, 신청기간을 비교한다.
4. 금액 또는 조건이 바뀌면 새 출처와 `checkedAt`을 함께 갱신한다.
5. 예산 소진, 접수 종료, 추가 공고처럼 상태가 바뀌는 경우 원문에서 확인한 내용만 반영한다.
6. 공식 문서에서 해당 지역에 지원이 없다고 명시한 경우에만 `confirmed-none`을 기록한다.
7. 아직 조사하지 않았거나 최신 공고를 확인하지 못한 지역은 데이터셋에 없는 상태로 두며 조회 결과는 `unverified`로 반환한다.
8. 지원 데이터 변경 PR은 해당 지역과 미확인 지역을 모두 테스트해 다른 지역 값이 새어 들어가지 않는지 확인한다.

## 다음 계산기에서의 사용 원칙

`CALC-3KW-001`과 `CALC-SUBSIDY-001`은 이 데이터 계약을 사용한다. `unverified` 상태일 때 다른 지역의 금액을 대신 계산하거나 `0원`을 표시하지 않는다. 화면에는 `확인된 정보 없음`으로 표현하고 공식 확인 경로와 기준일을 함께 제공한다.
