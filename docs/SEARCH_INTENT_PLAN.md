# SolPlanit Search Intent Plan

조사 기준일: 2026-08-08

이 문서는 검색량 숫자를 임의로 만들지 않고, 공개 검색 결과·공식 FAQ·경쟁 서비스의 입력 흐름을 이용해 **어떤 질문부터 계산기로 만들지** 결정하는 기준이다.

## 1. 관찰

### 한국에너지공단 FAQ

주택지원 FAQ의 대표 질문은 `주택지원사업이란 무엇인가요?`, `신청은 어떻게 하나요?`처럼 일반 사용자의 비용·지원·절차 질문에 집중되어 있다.

- https://www.knrec.or.kr/biz/faq/faq_list02.do?depth_1=A010000&depth_2=A010100

### 2026년 지역 지원 사례

관악구는 2026년 3kW 주택형 태양광에 한국에너지공단 지원과 지자체 지원을 함께 안내한다. 지역·연도에 따라 지원액이 달라지므로 전국 공통값처럼 다루면 안 된다.

- https://www.gwanak.go.kr/site/gwanak/08/10802020400002016082909.jsp

### 위치 기반 발전량

JRC PVGIS 5.3은 위치와 시스템 조건을 이용해 태양광 발전량을 계산할 수 있는 공개 API를 제공한다.

- https://joint-research-centre.ec.europa.eu/photovoltaic-geographical-information-system-pvgis/using-pvgis-5/api-non-interactive-service_en

### 일반 사용자용 해외 UX 참고

EnergySage의 태양광 계산기는 주소, 건물 유형, 월 전기요금처럼 사용자가 이미 알고 있는 정보부터 묻는다. 전문 시스템 손실률이나 일 발전시간을 첫 입력으로 요구하지 않는다.

- https://www.energysage.com/solar/calculator/

참고 목적은 화면 복제가 아니라 **입력 난이도와 질문 순서**다.

## 2. 핵심 검색 의도 우선순위

정확한 월 검색량을 확인할 수 있는 신뢰도 높은 키워드 플래너 데이터가 없는 상태에서는 숫자를 꾸며내지 않는다. 아래 순서는 검색 결과 반복성, 상업 의도, 공식 FAQ와 사용자 의사결정 순서를 함께 반영한다.

### Tier A — 가장 먼저 만든다

1. `태양광 3kw 설치비용`
2. `태양광 보조금` / `주택 태양광 보조금`
3. `태양광 전기요금 절감`
4. `태양광 발전량 계산`
5. `태양광 회수기간`

### Tier B — 설치 가능성 확인

6. `태양광 몇 kw 설치`
7. `태양광 패널 몇 장`
8. `태양광 설치 면적`
9. `태양광 방향 경사 발전량`
10. `3kw 태양광 발전량`

### Tier C — 정보 탐색

11. `가정용 태양광 단점`
12. `태양광 설치 전 확인사항`
13. `태양광 보조금 신청방법`
14. `태양광 설치비 견적 비교`

### Tier D — 발전사업자

15. `태양광 발전 수익 계산`
16. `SMP REC 수익 계산`
17. `REC 가중치`
18. `공장 지붕 태양광 수익`

주택용 검색자에게 Tier D 입력값을 기본으로 노출하지 않는다.

## 3. 페이지와 질문 매핑

| 사용자 질문 | 페이지 | 기본 입력 | 핵심 결과 |
|---|---|---|---|
| 3kW 설치하면 얼마예요? | `/calculators/solar-3kw-cost` | 지역 | 공식 사업 기준 설치비, 확인된 보조금, 자부담 |
| 우리 지역 보조금 있어요? | `/calculators/subsidy` | 지역 | 확인된 지원 내용, 대상, 기간 |
| 전기요금 얼마나 줄어요? | `/calculators/bill-savings` | 지역, 월 사용량, 설치 용량 | 설치 전/후 예상 요금, 연 절감액 |
| 얼마나 발전해요? | `/calculators/generation` | 위치, 설치 용량 | 월별·연간 발전량 |
| 몇 년이면 본전이에요? | `/calculators/payback` | 실부담액, 연간 절감액 | 단순 회수기간 |
| 지붕에 얼마나 올릴 수 있어요? | `/calculators/roof-capacity` | 건물 종류, 지붕 면적 | 설치 가능 용량, 패널 수 |

## 4. 데이터가 없는 경우의 UI

### 나쁜 처리

`보조금 0원`

공식 데이터를 아직 확인하지 못했는데 0원으로 보여주면 실제 지원이 없는 것으로 오해한다.

### 좋은 처리

`이 지역은 아직 확인된 2026년 지원 정보가 없습니다.`

그리고 공식 확인 경로를 제공한다.

## 5. 카피 규칙

검색어를 H1에 억지로 반복하지 않는다.

좋음:

- `3kW 태양광, 설치비가 얼마나 들까요?`
- `우리 지역에서 받을 수 있는 태양광 지원을 확인해보세요.`
- `월 전기 사용량을 넣으면 설치 전후 예상 요금을 비교합니다.`

피함:

- `2026 최신 태양광 설치비용 가격 비용 완벽 계산기`
- `최적의 태양광 솔루션을 경험하세요.`
- `자가소비 전력 가치를 입력하세요.`

---

## 6. Search Console 재정렬 규칙

실제 노출 데이터가 쌓이면 다음 지표를 보고 `TASK_QUEUE.md`를 다시 정렬한다.

1. 노출이 많은데 전용 계산기가 없는 검색어
2. 평균 게재순위 5~20위의 개선 가능 검색어
3. 노출 대비 CTR이 낮은 페이지
4. 계산 완료율이 높은 검색 의도
5. 관련 계산기로 이동이 잘 일어나는 페이지

공개 검색 추정보다 SolPlanit의 실제 Search Console 데이터를 우선한다.
