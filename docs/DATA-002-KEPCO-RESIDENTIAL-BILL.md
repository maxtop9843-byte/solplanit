# DATA-002 — 한국전력 주택용 전기요금 모델 검증

검증일: 2026-08-12

## 결론

SolPlanit의 주택용 절감 계산은 `주택용 저압`의 표준요금을 월 사용량과 계산 월로 계산한다. 단일 `원/kWh` 값은 사용하지 않는다.

현재 코드에 고정한 범위는 **2026년 3분기(7~9월)**다. 분기별로 바뀔 수 있는 연료비조정단가를 다른 분기에 재사용하지 않기 위해 1~6월·10~12월 요청은 `unavailable`로 돌린다.

## 검증한 요금 구조

- 기본요금: 910원 / 1,600원 / 7,300원
- 전력량요금: 120.0원 / 214.6원 / 307.3원 per kWh
- 평상시 누진구간: 200kWh / 400kWh
- 7~8월 누진구간: 300kWh / 450kWh
- 기후환경요금: 9.0원/kWh
- 2026년 3분기 연료비조정단가: 5.0원/kWh
- 부가가치세: 전기요금의 10%
- 전력산업기반기금: 전기요금의 2.7%

전력산업기반기금은 10원 미만을 버리고, 최종 표준요금도 10원 단위로 처리한다. 이 계산은 복지·대가족·생명유지장치·자동이체 할인, TV수신료처럼 고객별로 달라지는 항목을 포함하지 않는다.

## 공개 사례 교차검증

표준요금 모델은 한국전력이 2026년 여름에 공개한 사용량별 요금과 일치한다.

| 월 사용량 | 공개 요금 | 모델 결과 |
|---:|---:|---:|
| 419kWh | 77,760원 | 77,760원 |
| 443kWh | 83,940원 | 83,940원 |
| 484kWh | 104,480원 | 104,480원 |
| 524kWh | 118,970원 | 118,970원 |

이 fixture는 단가 하나만 맞는지 보는 테스트가 아니라 기본요금, 여름 누진구간, 기후환경요금, 연료비조정요금, 부가가치세, 기반기금과 끝자리 처리가 함께 맞는지 확인한다.

## 월 전기요금만으로 사용량을 역산하지 않는 이유

청구액에는 계약종별, 계절, 사용일수, 복지·대가족 할인, TV수신료 등 사용량 외의 정보가 섞일 수 있다. 같은 청구액이 항상 하나의 사용량을 뜻한다고 볼 수 없으므로 일반 입력은 **월 사용량(kWh) 중심**으로 유지한다.

사용자가 월 전기요금만 아는 경우에는 이를 정확한 kWh로 바꾸는 기능을 만들지 않는다. 향후 청구서의 계약종별·사용기간·할인 항목까지 함께 확인할 수 있을 때 별도 역산 흐름을 검토한다.

## 태양광 자가소비 처리 결정

시간대별 가정 부하가 없는데 `자가소비율 60%`처럼 하나의 비율을 임의로 넣지 않는다. 또한 사용자가 전문 비율을 직접 맞혀 입력하게 하지 않는다.

`CALC-SAVINGS-001`에서는 다음 원칙을 적용한다.

1. 설치 전 요금은 이 검증된 월 요금 모델로 계산한다.
2. 설치 후 요금은 **검증된 월 계통수전량**을 만들 수 있을 때만 같은 모델로 계산한다.
3. 월 사용량과 월 발전량만 있고 시간대 일치 근거가 없다면 정확한 절감액을 확정하지 않는다.
4. 자가소비 시나리오를 제공하려면 별도의 공식·공공 연구 근거를 데이터로 고정하고, 사용자가 비율을 맞혀 넣는 대신 근거가 보이는 범위로 제공한다.

즉, DATA-002는 요금 계산 경계를 검증했지만 태양광 발전량 전부가 곧바로 전기요금 절감으로 이어진다고 가정하지 않는다.
